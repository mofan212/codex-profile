disable-model-invocation: true
---

根据当前对话，**仅用 Markdown 围栏代码块** 输出一段可直接复制到新会话、用于完成已讨论任务的自包含提示词：

- 必须给出具体 Goal，并要求新会话创建后持续执行直至完成
- 保留已确认的目标、范围、约束和验收要求
- 记录已完成事项、剩余步骤、关键决策，以及新会话可访问的项目和文件位置；尚未开始时明确说明
- 保留最近的验证命令、结果和未验证项，以及会影响续跑的阻塞、失败尝试和已排除方案，不复制无关对话流水
- 要求新会话先核对当前文件和进度，再继续未完成工作，不重做仍然有效的已完成事项；没有依据的信息标为待确认，不编造路径或验证结果
- 允许按需启用 subagents
- 不得依赖当前会话上下文
- 使用紧凑的提示词结构，避免单次回复超过长度限制而被截断
