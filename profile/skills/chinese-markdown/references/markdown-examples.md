# 1. Markdown 规则与读取路由

用于处理中文 Markdown 的行内语法、标题层级、列表与表格尾部标点、省略号和技术符号。只在 `SKILL.md` 选择 `full_document` 或 `markdown_limited_check` 时读取。

| task | section |
| --- | --- |
| 检查行内代码、链接、强调、行内 HTML 或技术符号 | 读取「行内语法」 |
| 检查标题层级或编号 | 读取「标题层级」 |
| 检查列表或表格尾部标点 | 读取「尾部标点」 |
| 检查省略号 | 读取「省略号」 |
| 全文处理或最终校验 | 读取全部规则和「检查清单」 |

# 2. 行内语法

- Markdown 行内代码、链接、强调等语法与中文内容相邻时，两侧留一个半角空格
- `<span>...</span>` 等行内 HTML 标签与中文或数字正文相邻时，外侧留一个半角空格；后接中文全角标点或中文括号时保持紧邻
- Markdown 行内语法与中文标点相邻时保持紧邻，不在标点前后机械添加空格
- 同一字段名、配置项或命令参数已稳定使用行内代码时，可以在表格中统一格式，但不改写内容本身
- 保留行内代码、模板变量、正则、JSONPath、路径和函数签名中的技术符号语义，只处理符号外侧排版

```markdown
正确：运行 `example --help` 查看可用参数
错误：运行`example --help`查看可用参数

正确：不要引入 `Spec`、`Options`、`Config`。
错误：不要引入 `Spec` 、 `Options` 、 `Config` 。

正确：配置项包括 `timeout`、`retry`；默认值使用 `false`。
错误：配置项包括`timeout`、`retry`；默认值使用`false`。

正确：请 **先确认范围** 再继续修改
错误：请**先确认范围**再继续修改

正确：参考 [使用说明](guide.md) 完成配置
错误：参考[使用说明](guide.md)完成配置

正确：状态为 <span class="ok">通过</span>，继续执行
错误：状态为<span class="ok">通过</span> ，继续执行

正确：结果（<span class="ok">通过</span>）
错误：结果（ <span class="ok">通过</span> ）

正确：保留模板变量 `$VALUE$`、Shell 变量 `$PATH`、JSONPath `$` 和正则行尾 `$`
错误：保留模板变量 `VALUE`、Shell 变量 `PATH`、JSONPath 和正则行尾
```

# 3. 标题层级

格式基线及标题规则的适用条件以 `SKILL.md` 为唯一来源。本节只定义启用「仅 1、2 级标题且连续编号」约定后的具体规则。未启用该约定时，保留现有标题层级和编号；审查模式只报告相邻标题直接跳级、同一层级编号格式明显不一致等不依赖缺失上下文即可确认的问题。

启用两级连续编号约定后，执行以下规则：

- 2 级标题必须属于前一个 1 级标题
- 每个标题带层级编号并连续递增；编号从 0 或 1 起始，以完整文档基线为准
- 保持多个有实际职责的 1 级章节，不把全文塞入单个 1 级标题下的 2 级标题
- 修复编号时只改编号部分，不回滚标题文字中的其他排版修正
- 需要更细层级时使用引用块或列表，不新增 3 级或更深标题

启用连续编号约定时的正确示例：

```markdown
# 1. 背景
## 1.1 当前问题

# 2. 方案
## 2.1 实施步骤
```

既有文档使用 0 起始时，保留编号基线：

```markdown
# 0. 前言
## 0.1 背景

# 1. 正文
## 1.1 实施步骤
```

启用两级标题约定时的错误示例：

```markdown
# 1. 项目说明
## 1.1 背景
## 1.2 当前问题
## 1.3 方案
## 1.4 实施步骤
```

更细层级优先使用引用块：

```markdown
## 2.1 实施步骤

> 准备配置文件

准备配置文件的内容...

> 运行校验命令

运行校验命令的内容...
```

启用两级标题约定时，不新增 3 级或更深标题：

```markdown
## 2.1 实施步骤
### 2.1.1 准备配置文件

准备配置文件的内容...
```

# 4. 尾部标点

- 无序列表条目末尾不添加句号、分号、冒号、逗号或顿号
- 有序列表可以不加收尾符号；需要使用时，非最后一项使用分号，最后一项使用句号
- 列表项作为小标题并引出表格、代码块、引用块或子列表时，可以保留冒号
- Markdown 表格内文字末尾不添加收尾标点；内容必须保留原文标点时除外

正确示例：

```markdown
- 标题编号连续且层级正确
- 表格内文字末尾没有多余标点
- 命令和编码规则：

    | trigger | requirement |
    | --- | --- |
    | 执行 PowerShell 文件读写命令 | 显式附加 `-Encoding UTF8` |

1. 确认目标文档范围
2. 修正标题编号
3. 检查表格尾部标点

1. 确认目标文档范围；
2. 修正标题编号；
3. 检查表格尾部标点。

| trigger | action |
| --- | --- |
| 维护 Skill 文档 | 检查列表和表格尾部标点 |
```

错误示例：

```markdown
- 标题编号连续且层级正确。
- 表格内文字末尾没有多余标点；

1. 确认目标文档范围。
2. 修正标题编号：
3. 检查表格尾部标点；

| trigger | action |
| --- | --- |
| 维护 Skill 文档。 | 检查列表和表格尾部标点； |
```

# 5. 省略号

目标文档采用半角三点风格时，将正文中的普通省略表达统一为 `...`。不替换代码、路径通配符、语言变长参数、SQL 或函数签名中的语法性内容。

目标文档采用半角三点风格时：

```markdown
正确：等待任务完成...
错误：等待任务完成……
错误：等待任务完成......

正确：函数签名为 `fn(...args)`
错误：函数签名为 `fn(…args)`
```

# 6. 检查清单

- 行内语法与中文正文之间的半角空格正确，且中文标点旁没有误加空格
- 行内 HTML 外侧空格正确，且中文标点或中文括号前没有误加空格
- 标题处理符合当前格式基线；片段未被擅自重编号或改变层级
- 启用两级连续编号约定时，标题只使用 1 级和 2 级，编号连续并保持完整文档的既有起始值
- 无序列表、表格和有序列表的尾部标点符合对应规则
- 半角三点风格只应用于普通正文省略表达
- 字段名、配置项、命令参数、链接目标、模板变量和技术符号语义未改变
