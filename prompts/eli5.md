# ELI5

## 用途

通过延迟揭示概念的寓言建立直觉，再解释概念。

ELI5 是「Explain Like I'm 5」的缩写。

## 提示词

```text
I want you to take a concept from maybe grad school level in a given domain, and I'll tell you the domain at the end.

I want you to write me a parable that would fully explain that concept, but in an indirect way, like parables do.

Write it so that only toward the very end does it become clear what the concept is.

After that, write an explanation for the concept you were explaining.
```

## 备注

> 用法

将此提示词包装为名为 `eli5` 的 Skill 后，在 Codex 按以下方式使用：

```markdown
$eli5 how does DNS work
```

> 中文翻译

我希望你从某个给定领域中选取一个大致达到研究生水平的概念，我会在提示词的最后告诉你具体是什么领域。

请写一则能够充分阐释这个概念的寓言，但要像寓言惯常的做法那样，以间接方式表达。

故事需要写到临近结尾时，读者才能明白它所讲的究竟是什么概念。

寓言结束后，再清晰解释这个概念。
