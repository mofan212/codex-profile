# 提示词维护规则

## 存放边界

- `prompts/` 用于保存尚未充分验证或暂不足以沉淀为 Skill 的提示词
- 提示词不参与 Codex Profile 安装；只有用户明确要求时，才将成熟提示词迁移或整理为 `profile/skills/` 下的 Skill
- 用户提供或指定「原版」提示词时，除非用户明确要求修改原版，否则逐字保留；翻译、说明和改写版本不得静默替换原版

## 文件组织

| condition | action |
| --- | --- |
| 新增一个用途独立的提示词 | 新建一个 Markdown 文件 |
| 补充同一提示词的翻译、参数说明、使用方式或备注 | 写入同一文件 |
| 增加同一用途的轻微变体 | 写入同一文件，并明确标注原版与各变体 |
| 多个独立提示词共同组成一套完整工作流 | 建立同名子目录，每个独立提示词仍分别存放 |
| 新增提示词时已有匹配主题的子目录 | 将新提示词放入该子目录 |
| 新增提示词时没有匹配主题的子目录 | 继续平铺，不为单个提示词新建分类目录 |
| 同一用途已有多个平铺文件 | 建议按用途建立子目录；只有用户明确要求整理时，才批量移动既有文件 |

## 索引同步

- 首次建立分类子目录时，在 [README.md](README.md) 中增加分类索引
- README 已存在分类索引时，新增、移动、重命名或删除会改变索引内容的提示词或分类目录，同步更新 [README.md](README.md)
- README 只记录面向人类读者的目录说明和索引，AI 行为规则以本文件为准

## 完成检查

- 每个独立提示词都有唯一、可定位的 Markdown 文件；工作流子目录只用于组织这些文件
- 原版提示词与已有的翻译、备注和变体之间标签清晰，未在没有用户明确要求时改写原版
- 涉及目录结构或已索引路径时，README 已同步
- 未修改 Codex Profile 安装脚本或本机已安装配置
